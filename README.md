# SafeRouteApp

SafeRouteAI: aplicación móvil de rutas y reportes ciudadanos para Salamanca, Guanajuato.

La aplicación está en [`app/`](app/), con frontend React Native + Expo, backend Python +
FastAPI, PostgreSQL/PostGIS y servicios Azure configurables.

- [Instalación y ejecución](app/README.md)
- [Manual técnico y de usuario](app/docs/manual.md)
- [Manual PDF](app/docs/output/pdf/SafeRouteAI-manual.pdf)
- [Requisitos y validación](app/docs/VALIDATION.md)

Las claves y la configuración local se excluyen del repositorio. Usa las plantillas
`.env.example` para configurar tu entorno.
